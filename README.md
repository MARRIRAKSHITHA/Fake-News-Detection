# Fake News Detection Using Machine Learning

## Project Overview

This project detects whether a news article is Fake or Real using Natural Language Processing and Machine Learning.

## Objective

The objective of this project is to build a machine learning model that can classify news articles as Fake or Real based on their textual content.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## Methodology

1. Dataset Loading
2. Data Preprocessing
3. Train-Test Split
4. TF-IDF Vectorization
5. Logistic Regression Model Training
6. Model Evaluation
7. Fake/Real News Prediction

## Machine Learning Model

Logistic Regression was used as the classification algorithm.

## Results

The model achieved an accuracy of 98.86% on the test dataset.

The model achieved an AUC of 1.00.

## How to Run

1. Open "Fake_News_Detection_Project.ipynb" in Google Colab or Jupyter Notebook.
2. Install the required libraries using "requirements.txt".
3. Load the required dataset.
4. Run the notebook cells in order.
5. Enter a news article when prompted to obtain a Fake or Real prediction.
